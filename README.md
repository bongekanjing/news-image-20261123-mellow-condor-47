One page for Monday 23 November 2026, the day the UN climate summit in Antalya collapsed without a deal. The image sets the summit as the lead and carries six further stories from that day beneath it — the Ukrainian naval-drone attack that sank a Russian corvette in Benghazi, attacks on three more ships in the Strait of Hormuz, a factory fire in Cikande that killed 24, the Democrats' 258-seat US House majority, the EU–Indonesia trade agreement, and NATO intelligence reporting on Russia's nuclear-armed satellite — with the day's date on the masthead and its agencies credited at the foot.

The program beside the image does not copy it blind. `main.py` walks the PNG chunk by chunk, checks every CRC against the bytes it just read, checks that the header describes the pixels the image data actually holds, and refuses to hand the file over when it does not — so an entry that would be listed with a 0 is never written.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
